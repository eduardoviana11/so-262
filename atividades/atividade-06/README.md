# Atividade 06 - Sistemas Operacionais

Este diretório contém a resolução da **Atividade 06**, que tem como objetivo evidenciar a execução prática de gerenciamento de arquivos, diretórios e automação em ambiente Linux (Ubuntu), utilizando a máquina virtual remota do **Killer Coda**. Durante a prática, foram aplicados conceitos fundamentais do sistema, incluindo a navegação e inspeção de diretórios, bem como estruturação da árvore de pastas. A atividade também englobou a manipulação de arquivos, seguida pela cópia e movimentação desses arquivos entre os diretórios. Por fim, foi desenvolvida uma automação, ao qual foi concedida permissão de execução para realizar e validar a cópia de segurança dos dados.
